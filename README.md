# Nur PWA

Минималистичное мобильное PWA: локальный тасбих, скретч-карты с напоминаниями, карточки знаний, аудиоплеер Корана, многоязычный интерфейс и UI для подключения ИИ.

## Запуск

PWA и JSON-переводы требуют локального HTTP-сервера (не открывайте `index.html` двойным кликом). В каталоге `islamic-pwa` выполните одну из команд:

```powershell
python -m http.server 8080
# или
npx serve .
```

Откройте `http://localhost:8080`. Для установки PWA используйте HTTPS или `localhost`.

## Подключение ИИ

В приложении: **ИИ → «Подключить API безопасно»**. Укажите собственный защищённый endpoint, совместимый с OpenAI Chat Completions (`POST`, ответ `choices[0].message.content`). Не встраивайте рабочий ключ OpenAI в статический сайт: браузерный ключ виден пользователям. Для демонстрации без endpoint работает локальный безопасный ответ-заготовка.

## Структура

```text
islamic-pwa/
├─ index.html                 # разметка экранов
├─ css/styles.css             # адаптивный дизайн и анимации
├─ js/app.js                  # логика интерфейса
├─ js/data.js                 # контент, аудио-источники и системный промпт
├─ locales/{ru,en,ar,kk}.json # словари интерфейса и контента
├─ assets/icon.svg            # PWA-иконка
├─ manifest.webmanifest
└─ sw.js                      # офлайн-кэш интерфейса
```

Аудиозаписи загружаются по сети из открытых библиотек. Перед выпуском в продакшен проверьте права, работоспособность и разрешённость источников в целевых странах.
